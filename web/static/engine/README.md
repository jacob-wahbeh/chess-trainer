# Stockfish 19 (lite, single-threaded, WebAssembly)

From [nmrugg/stockfish.js](https://github.com/nmrugg/stockfish.js) release v19.0.1, a build of
[Stockfish](https://github.com/official-stockfish/Stockfish). Both are licensed under GPL-3.0; the
complete corresponding source is available at those repositories.

Re-download and verify with `npm run engine` (pinned SHA-256 in `scripts/fetch-engine.mjs`).
